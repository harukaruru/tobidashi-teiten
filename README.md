# トビダシ定点観測

飛び出し君（飛び出し坊や）を毎回同じ構図で撮影するためのスマホ向けWebカメラアプリ。

- **カメラ**：三分割グリッド＋前回写真の半透明ゴースト重ねで同じ構図に合わせて撮影
- **向き切替**：逆向きの飛び出し君はガイドを左右反転、撮影後に自動で反転補正して保存
- **位置情報**：取得できた場合のみGPS座標を記録（任意）
- **ライブラリ**：スポット別に整理、詳細表示、基準写真の設定、共有、削除
- **スライドショー**：スポット単位で古い順に再生（定点観測タイムラプス）
- **保存**：端末内（IndexedDB）。右上ボタンからJSONで書き出し／読み込み

単一ファイル（`index.html`）。ビルド不要。HTTPSで配信すればカメラと位置情報が使えます。

## 公開（GitHub Pages）

リポジトリの **Settings → Pages → Source: Deploy from a branch → Branch: `main` / `(root)`** を選んで保存。
数十秒後に `https://<ユーザー名>.github.io/tobidashi-teiten/` で開けます。
